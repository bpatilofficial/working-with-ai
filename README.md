# Working with AI — AI‑Assisted Coding
 
> Learning notes on using AI coding tools **effectively**: pair programming, agentic terminal workflows, automated code review — and knowing when *not* to use AI.
 
AI coding tools are genuinely changing how developers work, but only when used with judgment: understanding how models work, verifying everything they produce, and keeping the important decisions human. This repo documents the tools, workflows, and strategies I'm learning and using.
 
📺 Based on the [freeCodeCamp AI‑Assisted Coding course](https://www.youtube.com/watch?v=wlpBCazAY9Q) by **Beau Carnes**, plus my own strategy notes.
 
---
 
## The one‑line philosophy
 
> **AI speeds up implementation — you make the decisions.** AI is great at the *how*; you own the *what* and the *why*.
 
## Tools covered
 
| Tool | Best at |
|---|---|
| **GitHub Copilot** | Real‑time completions in VS Code, quick edits, learning new APIs |
| **CodeRabbit** | Automated PR review, quality gates, security analysis, planning |
| **Claude Code** | Complex refactoring, architectural discussion, autonomous terminal sessions |
| **Gemini CLI** | Huge context window, multimodal (images → code) |
| **OpenClaw** | Locally‑hosted background automation that orchestrates the other tools |
| **MCP** | Giving any of the above extra capabilities (web, DBs, browsers) |
